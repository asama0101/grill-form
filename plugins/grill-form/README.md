# grill-form

計画や設計を、ブラウザのフォームで答えながら詰めて、最後に SPEC（仕様書）にまとめる Claude Code 用のスキルです。バージョンは 1.0.0 です。

## 機能

- Claude からの質問に、ターミナルではなくブラウザのフォームで答えられます。候補を選ぶ、コメントを書く、保留にする、聞き返すが使えます。キーボードだけでも答えられます。
- 各質問に、Claude の推奨案と理由が付きます。決めることがなくなるまで、質問を重ねます。
- 依頼文と、参考資料（PDF・PowerPoint・Excel など）のパスを、最初に渡せます。
- 承認すると、SPEC の 1 ファイルだけが残ります。別のプラグインや別のセッションに、そのまま渡せます。

## 前提条件

- [Claude Code](https://docs.claude.com/en/docs/claude-code)
- Python 3.8 以上（標準ライブラリのみ）。ファイルを選ぶダイアログを使うときは、Python の tkinter も必要です（Windows 版の標準の Python には入っています）。
- [Playwright MCP](https://github.com/microsoft/playwright-mcp)。ローカルの HTML を開いて、送信を検知するために使います。このスキルには同梱していないので、導入方法の手順 3 で登録します。
- ブラウザ: Chrome か Edge を推奨します。
- OS: Windows 11 で動作を確認しています。macOS と Linux は、未検証です。

## 導入方法

### 1. マーケットプレイスを追加する

Claude Code で実行します。

```
/plugin marketplace add asama0101/grill-form
```

### 2. プラグインを入れる

```
/plugin install grill-form@grill-form
```

- 更新は `/plugin` の画面から行います。反映には Claude Code の再起動が必要です。

### 3. Playwright MCP を登録する

```bash
claude mcp add playwright --scope user -- npx @playwright/mcp@latest --allow-unrestricted-file-access --output-dir "$(python -c 'import tempfile; print(tempfile.gettempdir())')/playwright-mcp"
```

- `--allow-unrestricted-file-access`: `file://` の HTML を開くために必要です。
- `--output-dir`: Playwright MCP が保存する記録の置き場所です。指定しないと作業フォルダに `.playwright-mcp/` ができるので、OS の一時フォルダ配下にします。上のコマンドは、OS の一時フォルダを Python で調べて埋めます。
- ブラウザを指定するときは、`--browser chrome` などを追加します。
- すでに `playwright` を登録している場合は、上書きされません。[困ったとき](#困ったとき)の手順で登録し直してください。

登録したら、Claude Code を再起動します。`claude mcp list` に `playwright` が出れば成功です。

## 使い方

Claude Code で、次のように頼みます。

```
/grill-form:grill-form API の認証方式を詰めたい
```

「grill して」だけでは起動しません。`/grill-form:grill-form` を呼ぶか、「grill-form で〜」「HTML で grilling」と明示したときだけ、このスキルが使われます。

起動すると、ブラウザに入力フォームが開きます。ブラウザで「送信」を押すと、Claude が自動で検知して次へ進みます。ターミナルへの入力は要りません。途中でやめるときは、どのフォームでも「中止」を 2 回押します（SPEC は作られません）。

1. **入力フォーム**: 依頼文、ファイルパス、保存先を渡します。依頼文とファイルパスは、どちらか 1 つだけでも構いません。
2. **事前確認**: 目的とゴール、障壁、制約を確認します。Claude が推奨案を埋めるので、確認と修正だけです。
3. **質問ラウンド**: 質問のフォームが開きます。決めることがなくなるまで、何度か繰り返します。
4. **最終確認**: SPEC 案が表示されます。「承認」で確定すると、SPEC のファイルが作られ、Claude がそのパスを知らせます。「修正あり」を選ぶと、コメントを反映した案が、また表示されます。

### 入力フォームの欄

| 欄 | 内容 |
| --- | --- |
| 依頼文 | 何を詰めたいか、背景、分かっている制約など |
| ファイルパス | 参考資料のパス。1 行に 1 つ。Claude が元の場所から直接読みます（コピーしません）。「ダイアログで選ぶ」にチェックすると、送信後にファイルを選ぶダイアログが開きます（複数選べます。手入力のパスと併用できます） |
| 保存先（親フォルダ） | SPEC を置くフォルダ。初めは作業フォルダ（Claude Code を動かしているフォルダ）が入っていて、変更できます。詳しくは[設定](#設定)を見てください |

- PDF・PowerPoint・Excel は、Claude が pdf・pptx・xlsx スキルで読みます。
- PDF の図形は、Claude がページを画像として読みます。PowerPoint と Excel は、文字と図形の構造しか読めません。図形が重要なときは、PDF に書き出して渡してください。

### 質問への答え方

- 画面の左に、進み具合と質問の一覧が出ます。いま答えている質問は、青い枠と「いま答えている質問」の札で示されます。一覧の「●」は回答済み、「△」は保留、「?」は要確認、「○」は未回答です。
- 候補をクリックするか、候補の左にある文字（`A`・`B`・`C`…）のキーを押して選びます。`J` で次の質問、`K` で前の質問へ移れます。
- 1 つだけ選ぶ質問は、マウスか文字キーで選ぶと、次の質問へ移ります（矢印キーで動かしただけでは移りません）。複数選べる質問は移りません。
- 緑の札「推奨」の候補が、Claude の推奨案です。理由は、候補の下に出ます。
- 「コメント」を押すと、コメント欄が開きます。候補を選んだときのコメントは、理由や条件の補足です。候補を選ばずに書いたコメントは、それ自体が回答になります。候補にない回答は、候補を選ばずにコメントに書いてください。
- 今決められないときは、「あとで決める」を押します。
- 質問の意味が分からないときは、「聞き返す」を押して書き、送信します。次のラウンドで、Claude が説明か補足質問を返します。聞き返しが残っている間は、質問は終わりません。
- 選んだ候補を取り消して、コメントだけで答えたいときは、「選択をクリア」を押します。

### 残るもの

承認すると、SPEC の 1 ファイルが残ります。

```
<保存先>/SPEC-<テーマ>-<日付>.md
```

- 例: `SPEC-api-design-2026-10-24.md`。同じテーマを同じ日に 2 回承認したときは、末尾に連番（`-2`、`-3`）が付きます。既存のファイルは上書きしません。
- SPEC は、概要・流れ・受入条件・非目標・リスク・決定ログで構成されます。概要の「入力」に、依頼文の要約と、渡したファイルの元のパスが入ります。
- 依頼文の原文、質問と回答の履歴、入力ファイルは残りません。入力ファイルはコピーしないので、元のファイルを動かすと辿れなくなります。
- 別のプラグインや別のセッションに引き継ぐときは、このファイルを渡します。

## 設定

### SPEC の保存先

入力フォームの「保存先（親フォルダ）」欄で、毎回指定できます。

- 初期値: 作業フォルダの絶対パスが入っています。そのままなら、作業フォルダの直下に保存されます。
- 空欄: 作業フォルダの直下です。
- フォルダを書く: 相対パスは作業フォルダから、絶対パスはそのまま使われます。存在しないフォルダのときは、Claude が、新しく作ってよいかを尋ねます。

保存先は、そのまま git の管理対象になります。機密を書いたときは、`.gitignore` に `SPEC-*.md` を加えてください。

### Playwright MCP のオプション

導入方法の手順 3 で付けるオプションです。ブラウザを変えるときは `--browser chrome` などを足します。

## 困ったとき

**スキルが起動しない**
- 「grill-form で〜」か「HTML で grilling」と明示して頼んでください。「grill して」だけでは、通常の `grilling` スキルが使われます。
- 入れた直後は、Claude Code を再起動してください。`/plugin` で `grill-form` が有効か確認できます。

**Playwright MCP のツール（`browser_*`）がないと言われる**
- 導入方法の手順 3 で登録し、Claude Code を再起動してください。`claude mcp list` で `playwright` を確認できます。

**すでに `playwright` を登録していて、`claude mcp add` が効かない**
1. `claude mcp get playwright` で、現在の引数とスコープを確認します。
2. `claude mcp remove playwright --scope <スコープ>` で削除します。
3. 元の引数を残したまま、`--allow-unrestricted-file-access` と `--output-dir` を付けて登録し直します。
4. Claude Code を再起動します。

**`file://` のページが開けない**
- Playwright MCP に `--allow-unrestricted-file-access` が付いているか確認してください。

**送信が検知されない**
- ブラウザの「送信」を押したあと、「送信しました」と表示されるか確認してください。
- 約 30 分待っても送信がないと、Claude が続行方法を聞きます。フォームの「Markdown をコピー」で、回答を貼る方法もあります。

**ファイルを選ぶダイアログが開かない**
- ファイルを選ぶダイアログは、入力フォームの送信後に、別のウィンドウで開きます。タスクバーを確認してください。
- Python の tkinter がない環境や、画面のない環境では開けません。そのときは、Claude がチャットでパスを尋ねるので、答えてください。

**ファイルパスが読めない**
- 存在しないパスや、フォルダのパスは読めません。ファイルのパスを書いてください。Claude から、再入力を求められます。

**PowerPoint・Excel の図形が読めない**
- 文字と図形の構造しか読めません。PDF に書き出して渡すか、図の内容を依頼文に書いてください。

**SPEC が想定外の場所にできた**
- 保存先は、入力フォームの「保存先」欄で決まります。初期値は作業フォルダです。サブフォルダで Claude Code を起動していないか確認してください。

**一時フォルダの削除に失敗した**
- シェルのカレントフォルダが、一時セッションの中にないか確認してください。SPEC は保存済みです。残った一時フォルダは、次回の実行時に、3 日より古いものから自動で削除されます。

**日本語のテーマ名が文字化けする**
- テーマ名は、ASCII の短い名前（例: `api-design`）にしてください。

**`python` コマンドが見つからない**
- `python3` と読み替えます。Claude は、自動で読み替えます。
